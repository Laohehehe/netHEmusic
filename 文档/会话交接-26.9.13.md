## 四、血泪教训（务必遵守）

1. **C# 设置白名单**：`MainWindow.HandleSetSetting` 的 default 分支只放行 `fx_ / ui_ / lyric_ / hk_ / vz_ / perf_` 前缀。**新设置键名必须用这些前缀**，否则前端存不进去、静默失效（淡化、打卡都栽过）
2. **前端 app.js 语法错误 = 页面卡「加载中…」且所有交互失效**。已装 `window.onerror` → `[jserr]` 上报。改完先 `node --check`
3. **不要用正则删代码**：曾把 `try` 后面的 `catch` 一起删掉 → 上面那个致命 bug。**改用逐行精确替换**
4. **不要用数组拼字符串生成补丁**；补丁脚本尽量简单
5. **修 bug 前先确认那个函数真的被调用**（`cd3f010` 就栽在这：改了死代码 `fadeOutThenPause`，真路径 `auPause` 没动）
6. **命名空间坑**：MainWindow.xaml.cs 里写 `Windows.Storage.…` 会被解析成项目自己的 `netHEmusic.Windows.…` → 要么在文件顶部 `using Windows.Storage.…`，要么写 `global::Windows.…`
7. **WinRT `FolderPicker` 在未打包 WinUI3 里不可用**：`PickSingleFolderAsync` 直接抛 `COMException 0x80004005 (E_FAIL)`。选文件夹用 Win32 `IFileOpenDialog + FOS_PICKFOLDERS`（见 `Core/Native/FolderPickerDialog.cs`）
8. **每步验证**：语法检查 → 启动日志（含 `[jserr]`）→ 截图确认；**改完立即 commit + push**
9. **测试动过用户配置要还原**（本轮测试改过 `[Download] dir`，已还原成 `D:\hyzhehehe\Music\netHemusicDL`）
10. PowerShell 5.1 按 GBK 读 .ps1，**脚本里的中文会乱码**；自动化脚本尽量写英文注释
11. 删除文件**必须先问用户**，且移入回收站
