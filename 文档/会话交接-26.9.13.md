## 四、血泪教训（务必遵守）

1. **C# 设置白名单**：`MainWindow.HandleSetSetting` 的 default 分支只放行 `fx_ / ui_ / lyric_ / hk_ / vz_ / perf_` 前缀。**新设置键名必须用这些前缀**，否则前端存不进去、静默失效（淡化、打卡都栽过）
2. **前端 app.js 语法错误 = 页面卡「加载中…」且所有交互失效**（整个脚本不执行）。已装 `window.onerror` → `[jserr]` 上报，日志里能直接看到文件名+行号
3. **不要用正则删代码**：曾把 `try` 后面的 `catch` 一起删掉 → 上面那个致命 bug。**改用逐行精确替换**
4. **不要用数组拼字符串生成补丁**：引号/转义极易写坏（发生过 SyntaxError）。补丁脚本尽量简单，写完先 `node --check`
5. **每步验证**：语法检查 → 启动日志（含 `[jserr]`）→ 必要时截图；**改完立即 commit + push**（用户明确要求，作为回退保险）
6. PowerShell 5.1 按 GBK 读 .ps1，**脚本里的中文会乱码**：需要中文就写到 .js 里用 Node 处理，或把中文作为参数/环境变量传入
7. 删除文件**必须先问用户**，且移入回收站（`Microsoft.VisualBasic.FileIO.FileSystem.DeleteFile(..., SendToRecycleBin)`）
